# 문제와 범위

## 업무 가정

강습 운영 담당자가 이전 달 수강생의 다음 달 유지 여부와 미등록 대상을 반복 확인하고, 유지율이 하락한 강습을 먼저 살펴보고 싶다는 조회 업무를 가정합니다. 기존 화면의 클릭 수·업무 소요 시간·현장 인터뷰 결과는 이 자료에서 측정하거나 공개하지 않습니다. 효용은 검증 대상 가설입니다.

## 검증하려는 질문

- 같은 의미의 자연어를 적절한 Tool과 강습·월·필터로 해석할 수 있는가.
- 여러 Tool을 허용하되 조회 범위를 검증하고 잘못된 인자나 오류를 제어할 수 있는가.
- 계산과 개인정보 처리를 모델 판단에서 분리할 수 있는가.
- 단일 유지율 조회에서 여러 강습의 하락 비교와 후속 명단 확인으로 확장할 수 있는가.

## 데이터와 지표

합성5강습의 2026년9·10·11월 데이터입니다. 유효·결제완료·미취소 등록 중 해당 월과 수강 기간이 겹치는 회원을 중복 제거합니다.

```text
유지율 = |기준 월 회원 ∩ 다음 달 회원| / |기준 월 회원| × 100
변화(%p) = 현재 구간 유지율 − 직전 구간 유지율
```

예: 9→10월80%, 10→11월75%라면 −5%p입니다. 상대 하락률 −6.25%와 다릅니다. 분모0은 null/산출 불가이며 하락 순위에서 제외합니다. 임계값 판정과 정렬은 반올림 전 값으로 수행합니다.

장기 등록으로 기간이 이어지는 회원도 유지로 포함합니다. 새로운 재신청만의 비율과 동일하지 않으며 미등록 확인이 곧 최종 이탈이나 하락 원인을 뜻하지 않습니다.

## 구현 범위와 공개 범위

구현 경험은 합성 데이터 조회, 로컬 모델 Tool Calling, 계산·입력 검증, 명단의 로컬 표시와 비교 화면입니다. 이 문서 저장소에는 그 계약·근거·출력만 포함합니다. 특정 업무 시스템의 인증·API·DB 매핑은 포함하지 않습니다.

정식 운영 도입, 실제 업무 효과, 과거 시점 확정 통계, 인과 분석은 아직 입증하지 않았습니다.

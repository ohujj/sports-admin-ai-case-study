# Tool 설계

Tool은 모델이 임의 SQL이나 URL을 만들어 실행하는 권한이 아니라, 코드가 검증하는 업무 기능입니다. 자연어의 의도·강습·기간 해석은 모델, 업무 지표와 오류 처리는 코드가 책임집니다.

## 1. read_programs

- 선택 조건: 강습 이름/코드를 찾거나 동명이름을 구분해야 할 때.
- 인자: `search_keyword`(검색어 또는 null).
- 반환: 강습 코드/이름 미리보기, 전체 건수, `truncated` 여부.
- 경계: 미리보기20개는 분석 대상 수 제한이 아닙니다. 일부를 전체 목록으로 설명하지 않습니다.

## 2. read_retention_summary

- 선택 조건: 한 강습의 특정 월→바로 다음 달 유지율 요청.
- 인자: `program_code`, `base_month`, `target_month`.
- 검증: 월 형식·실제 달·인접 월, 지원 데이터 기간, 알려진 강습, 추가 필드 거부.
- 반환: 기준/유지/미유지 인원, 유지율, 데이터 기준 시점과 지표 정의.
- 경계: 모델이 비율을 계산하거나 없는 데이터를 추정하지 않습니다. 분모0은 null입니다.

## 3. show_retention_members

- 선택 조건: 유지/미유지/전체 명단 요청.
- 인자: 위 조회 조건과 `status`(retained/not_retained/all).
- 반환: 화면에는 합성 회원 행, 모델에는 요약·명단 건수·로컬 표시 여부만 반환.
- 경계: 회원 행·이름·식별값을 모델 대화에 재입력하지 않습니다. 후속 질문의 이전 조건은 서버 검증을 대체하지 않습니다.

## 4. read_retention_declines

- 선택 조건: 여러 강습의 유지율 하락 비교 또는 하락 폭 임계값 요청.
- 인자: `base_month`, `target_month`, `program_codes`, `min_drop_pp`, `search_keyword`.
- 빈 코드 배열: 검색어 또는 전체 강습 범위를 분석. 특정 코드와 검색어는 함께 받지 않음.
- 반환: 분석 전체/하락/산출 불가 건수, 강습별 이전·현재 분모와 유지 인원, 비율·변화·상태.
- 경계: 분석 개수 상한은 두지 않았습니다. 모델에는 상위10개 간략 집계와 전체 건수를 전달하고 화면에는 전체 결과를 표시합니다. 모델 문맥 제한을 분석 대상 축소로 바꾸지 않습니다.
- 실패: 잘못된 범위·없는 데이터·조회 오류는 실패로 구분하며 일부를 전체 성공이나0명으로 표시하지 않습니다.

## 후속 조회와 한도

하락 분석 결과에서 강습을 선택해 같은 기간의 미등록 명단을 확인할 수 있습니다. 한 질문 안의 후속 조회는 분석에 포함된 강습·기간만 허용합니다. 단일 조회끼리는 한 질문에 한 강습·기간을 유지합니다.

요청당 모델4회/Tool6회·동시 AI질문1개, 자동 재시도 없음은 계산 대상 강습 수 상한과 다른 실행 제어입니다. 애플리케이션은 허용 Tool 이름·인자 스키마를 재검증합니다.

전체 JSON 계약은 [tool-schemas.json](tool-schemas.json)을 참고하세요. 공개 데모 계약이며 외부 회사 API 계약을 노출하거나 재현하는 문서가 아닙니다.

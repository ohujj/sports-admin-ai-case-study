# 공개 파일 범위

## 포함 후보

- app/: 직접 작성한 합성 데이터, 계산·Tool Calling·로컬UI 코드 중 검토한 파일.
- docs/MOCK_DATA_GUIDE.md,이문서,README.md,SECURITY.md: 일반화한 작성/실행/공개 기준.
- examples/: 합성 출처를 기록하고 계산과 대조한 두JSON.
- requirements*.txt,start*.ps1: 확인한 의존성과 로컬실행.
- .gitignore: 기본거부+정확파일허용 목록.

현재로컬AGENTS.md에는개인작업범위/과거변경지시가있으므로업로드대상에서제외합니다. 공개작업기준은이문서와SECURITY.md에남깁니다. 내부VERIFICATION.md를그대로공개하지않고,필요시합성검증범위·버전·한계를별도자료로작성해검토후허용합니다.

## 제외

가상환경/모델/바이너리,환경변수/키/토큰/인증서,DB/원문응답/실데이터/CSV덤프,로그/백업/내부검토·승인/개인메모,퇴역연동파일과회사소스/내부계약은제외합니다.새파일은이름이안전해보여도기본차단됩니다.

## 변경·업로드 절차

1. 실제대상과데이터출처·권한·외부처리를SECURITY기준으로확인합니다.
2. 새파일/이미지/예시에회사식별·실데이터·비밀/내부구조가없는지검토합니다.
3. 공개가능한정확한경로만.gitignore의허용목록에추가합니다. 폴더전체허용이나포괄확장자허용은하지않습니다.
4. Git을쓸때는실제추적/staged blob과이력까지검사합니다. .gitignore는이미추적된파일/과거이력/수동업로드를제거하지않습니다.
5. 별도요청받은commit/push만수행합니다. 이문서는원격생성·archive해제·공개전환을자동허가하지않습니다.

이저장소는Mock전용실행코드와합성예시를공유합니다. 이전문서형커밋의자료는과거버전이며현재실행결과로재라벨하지않습니다. 앞으로도변경된범위·출처·실제추적파일과이력을다시확인합니다.
